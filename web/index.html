로컬 서버(VirtualMouse-Agent)가 실행 중이 아닙니다 오프라인

이 대시보드는 서버가 꺼져 있어도 열립니다. 이미 에이전트를 설치했다면 아래 [로컬 서버 실행]을 눌러 바로 기동하세요.

VirtualMouse-Agent.exe 다운로드

최초 1회 브라우저에서 「VirtualMouse Agent 열기」 확인 창이 뜨면 항상 허용을 체크해 주세요. 이후 대시보드를 열면 자동으로 로컬 서버가 실행됩니다.

로컬 에이전트 API 토큰 입력 필요 인증 대기

작업 표시줄의 VM 트레이 아이콘을 우클릭해 API 토큰 복사를 누른 뒤 아래에 붙여 넣으세요. 한 번 저장하면 이 브라우저(및 설치한 PWA 앱)에서 계속 자동 연결됩니다.

PC에 대시보드 앱(PWA) 설치하기 권장

브라우저의 앱 설치 기능을 사용하면 바탕화면·시작 메뉴에 독립 앱으로 등록되며, 로컬 서버가 꺼져 있어도 즉시 실행되어 자동으로 로컬 서버를 기동합니다.

PC 1단계

대기

순정 Arduino Uno R3인 경우, USB 포트 바로 옆 6핀 헤더 중 가장 가까운 2개 핀(RESET-GND)을 점퍼선으로 1초간 접촉했다 떼어 주세요.

WinUSB 드라이버 설치 (최초 1회)

[드라이버 자동 설치]를 누르면 에이전트가 libwdi(wdi-simple)로 이 장치(03EB:2FEF)에만 WinUSB 드라이버를 설치합니다. Windows 사용자 계정 컨트롤 창이 뜨면 [예]를 눌러 주세요. 창이 보이지 않으면 작업 표시줄에서 깜빡이는 방패 아이콘을 누르세요.

설치할 때 libwdi가 만든 자체 서명 인증서가 이 PC의 신뢰할 수 있는 인증서 저장소에 추가됩니다 (Zadig와 같은 방식, 서명이 끝나면 개인 키는 지워짐).

직접 설치하려면 (Zadig):

  1. Zadig를 내려받아 실행합니다.
  2. 메뉴 Options → List All Devices를 켭니다.
  3. 목록에서 ATmega16U2 DFU 또는 USB ID가 03EB 2FEF인 장치를 고릅니다.
  4. 오른쪽 드라이버를 WinUSB로 두고 Install Driver(또는 Replace Driver)를 누릅니다.
  5. 설치가 끝나면 이 화면이 자동으로 다음 단계로 넘어갑니다.

PC API 안내

외부 프로그램에서 PC Virtual Mouse 제어하기

Python, C#, Node.js, PowerShell, AutoHotkey 등 PC에서 실행하는 프로그램은 POST http://127.0.0.1:18080/action으로 JSON({}) 객체만 전송하면 서버 내부의 사람 움직임 엔진(베지어 곡선·가감속·손떨림·DPI 보정)이 자동으로 처리해 물리 USB 마우스/키보드로 입력합니다. 모든 요청에는 API 토큰을 Authorization: Bearer <토큰> 헤더로 함께 보내야 합니다.

토큰은 에이전트가 처음 실행될 때 만들어 %LOCALAPPDATA%\VirtualMouse\api-token 파일에 저장합니다. 트레이 메뉴의 API 토큰 복사로도 꺼낼 수 있습니다. 토큰을 바꾸려면 이 파일을 지우고 에이전트를 다시 시작하세요.

1. 호출 예시

PowerShell 
$token = Get-Content "$env:LOCALAPPDATA\VirtualMouse\api-token"
Invoke-RestMethod -Method Post -Uri "http://127.0.0.1:18080/action" `
  -Headers @{ Authorization = "Bearer $token" } `
  -ContentType "application/json" `
  -Body '{"action": "click_at", "x": 800, "y": 500, "button": "L"}'
Python 
import os, requests

token_file = os.path.join(os.environ["LOCALAPPDATA"], "VirtualMouse", "api-token")
token = open(token_file, encoding="utf-8").read().strip()

requests.post("http://127.0.0.1:18080/action",
    headers={"Authorization": f"Bearer {token}"},
    json={
        "actions": [
            {"action": "click_at", "x": 800, "y": 500, "button": "L"},
            {"action": "sleep", "ms": 150},
            {"action": "type", "text": "123456"},
            {"action": "hotkey", "keys": ["enter"]}
        ]
    })
Node.js (.mjs) 
import { readFileSync } from "node:fs";
import { join } from "node:path";
const token = readFileSync(
  join(process.env.LOCALAPPDATA, "VirtualMouse", "api-token"), "utf8").trim();

await fetch("http://127.0.0.1:18080/action", {
  method: "POST",
  headers: { "Content-Type": "application/json", Authorization: `Bearer ${token}` },
  body: JSON.stringify({ action: "move_to", x: 640, y: 360 })
});

2. 보안 규칙과 요청 한도

  • 브라우저에서는 이 대시보드(virtual-mouse.iseohyun.com)와 로컬 가이드(127.0.0.1:18080)만 호출할 수 있습니다. 다른 웹페이지의 요청은 거부됩니다.
  • POST 요청은 Content-Type: application/json만 받습니다. 토큰이 없거나 틀리면 401을 돌려줍니다.
  • 한도: 요청 하나에 actions 200개·본문 64KB, 동작 하나에 sleep 10초·text 2,000자·scroll ±100틱·duration 5초·hotkey 키 8개까지 받습니다. 버튼은 L/R/M만, 좌표·이동량은 ±32767까지입니다.
  • 타이핑은 ASCII 글자와 줄바꿈·탭만 됩니다. 지원하지 않는 글자가 있으면 한 글자도 입력하지 않고 400을 돌려줍니다.
  • {"action": "release_all"}(비상 정지)은 진행 중인 동작을 끊고, 그 전에 줄 서 있던 요청도 취소한 뒤 즉시 실행됩니다. 취소된 요청은 409를 받습니다. 사이드바와 트레이 메뉴의 비상 정지도 같습니다.
  • 서버 로그에는 타이핑한 글자를 남기지 않습니다.

절대 이동{"action": "move_to", "x": 800, "y": 500}화면 물리 픽셀 좌표로 정밀 안착

이동 후 클릭{"action": "click_at", "x": 800, "y": 500}이동 → 짧은 정지 → 클릭 원샷
더블클릭{"action": "double_click", "button": "L"}자연스러운 간격 2회 클릭

BT API 안내

외부 프로그램에서 모바일 BT Virtual Mouse 제어하기

ESP32 BLE 장치가 연결된 상태에서도 PC 모드와 동일한 로컬 엔드포인트 POST http://127.0.0.1:18080/action과 Authorization: Bearer <토큰>을 사용합니다. 모바일 화면은 PC OS가 커서 좌표를 직접 읽을 수 없으므로 상대 이동(move) · 클릭(click) · 스크롤(scroll) 명령을 사용합니다.

1. 모바일 BT 호출 예시

PowerShell 
$token = Get-Content "$env:LOCALAPPDATA\VirtualMouse\api-token"
Invoke-RestMethod -Method Post -Uri "http://127.0.0.1:18080/action" `
  -Headers @{ Authorization = "Bearer $token" } `
  -ContentType "application/json" `
  -Body '{"action": "bt_demo"}'
Python 
import os, requests

token_file = os.path.join(os.environ["LOCALAPPDATA"], "VirtualMouse", "api-token")
token = open(token_file, encoding="utf-8").read().strip()

requests.post("http://127.0.0.1:18080/action",
    headers={"Authorization": f"Bearer {token}"},
    json={
        "actions": [
            {"action": "move", "dx": 120, "dy": 40},
            {"action": "sleep", "ms": 120},
            {"action": "click", "button": "L"},
            {"action": "scroll", "delta": -4}
        ]
    })

3. ESP32 개발 참고 사항

  • 에이전트는 ESP32 시리얼 포트를 열 때 DTR/RTS를 False로 유지하여 BLE 페어링이 끊기지 않도록 보호합니다.
  • PC(Arduino Uno)와 BT(ESP32)는 한 번에 하나의 장치를 자동 감지해 운용합니다.
