하드웨어 USB 마우스 & 키보드 올인원 세팅

Arduino Uno R3를 물리 USB HID 장치로 설정하고, 로컬 API(127.0.0.1:18080)를 통해 사람처럼 자연스럽게 동작하는지 바로 테스트합니다.

1단계

DFU 모드 진입 & 펌웨어 설치

대기

순정 Arduino Uno R3인 경우, USB 포트 바로 옆 6핀 헤더 중 가장 가까운 2개 핀(RESET-GND)을 점퍼선으로 1초간 접촉했다 떼어 주세요.

2단계

USB 재연결 & 장치 확인

대기

플래싱이 끝나면 USB 케이블을 한 번 뺐다가 다시 연결하세요. HID 마우스, HID 키보드, COM 포트가 자동으로 감지됩니다.

로컬 API 서버 연결
